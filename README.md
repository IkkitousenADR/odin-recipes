# Introduction

This project aims to practice and showcase all of the HTML knowledge acquired throughout the TOP lessons and outside the platform.

In this project, you are going to build a basic recipe website.

The website will consist of a main index page which will have links to a few recipes. The website doesn't have to look very pretty for now, since the whole point of this project is to build a knack for HTML chops; will revisit this project in preceeding lesson to style it up with CSS.
